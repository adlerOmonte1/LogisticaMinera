# Requerimientos de usuario — M09 Auditoría

| Código | Requerimiento |
|---|---|
| RU-M09-01 | Quiero que quede anotado quién registró, corrigió o anuló cada cosa, y cuándo |
| RU-M09-02 | Si un dato cambió, quiero poder ver cómo estaba antes y cómo quedó después |
| RU-M09-03 | Si alguien intenta hacer algo que no le corresponde, quiero que eso también quede anotado |
| RU-M09-04 | Ante cualquier duda sobre un registro, quiero poder ver su historial completo |

## Contexto del diagnóstico

| Requerimiento | Situación que resuelve |
|---|---|
| RU-M09-01, RU-M09-02 | Hoy corregir un dato significa tachar el papel, y no queda constancia de qué decía antes ni de quién lo cambió |
| RU-M09-03 | No hay forma de saber si alguien intentó una operación que no le correspondía |
| RU-M09-04 | Ante una duda sobre un registro, no hay dónde reconstruir su historia: solo existe su estado actual |
