# Requerimientos de usuario — M02 Catálogo maestro

| Código | Requerimiento |
|---|---|
| RU-M02-01 | Necesito saber cuáles volquetes son nuestros y cuáles son alquilados, porque no se controlan igual |
| RU-M02-02 | Quiero elegir el tipo de mineral de una lista, no escribirlo cada vez, porque a veces se escribe distinto y después no cuadra |
| RU-M02-03 | Los transportistas deben estar registrados con su RUC para no confundirlos |
| RU-M02-04 | Si dejamos de trabajar con un transportista o un vehículo, no quiero que desaparezca lo que ya movió |

## Contexto del diagnóstico

| Requerimiento | Situación que resuelve |
|---|---|
| RU-M02-01 | La titularidad del vehículo se anotaba de memoria, con distintas palabras según quién registrara |
| RU-M02-02 | El tipo de mineral se anotaba a mano con denominaciones variables, lo que impedía consolidar la producción de forma consistente |
| RU-M02-03, RU-M02-04 | Los transportistas y vehículos se identificaban de forma libre, sin un registro que sobreviviera a los cambios de personal |
