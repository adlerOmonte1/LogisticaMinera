# Requerimientos de usuario — M02 Catálogo maestro

| Código | Requerimiento |
|---|---|
| RU-M02-01 | Quiero elegir el producto de una lista, no escribirlo cada vez, porque a veces lo escriben distinto y después no cuadra |
| RU-M02-02 | Necesito saber cuáles volquetes son nuestros y cuáles son alquilados, porque no se controlan igual |
| RU-M02-03 | Los transportistas deben estar registrados con su RUC para no confundirlos |
| RU-M02-04 | Si dejamos de trabajar con un transportista, no quiero que desaparezca lo que ya movió |
| RU-M02-05 | Quiero que la lista de clientes esté disponible cuando registre una venta |

**Origen:** el requerimiento RU-M02-01 responde a un problema observado en el diagnóstico: los productos se anotaban a mano con denominaciones variables, lo que impedía consolidar la producción por producto.
