# Requerimientos de usuario — M05 Existencias

| Código | Requerimiento |
|---|---|
| RU-M05-01 | Quiero saber cuánto hay de cada producto sin ponerme a sumar papeles |
| RU-M05-02 | Necesito poder explicar de dónde salió ese número, movimiento por movimiento |
| RU-M05-03 | Cuando medimos en planta y no coincide con el sistema, quiero registrar la diferencia, no taparla |
| RU-M05-04 | Nadie debería poder escribir un número de stock a mano |

## Contexto del diagnóstico

RU-M05-01 responde al proceso actual: determinar el stock de un producto exige revisar los reportes semanales y los tickets archivados, y toma varios minutos por producto. Ese tiempo es el indicador I3.

RU-M05-04 es una exigencia de integridad que el propio personal planteó: si el stock fuera editable, dejaría de ser una consecuencia de los registros y pasaría a ser una opinión.
